# Skylar｜嵌入式系统与工程项目集

这里集中展示 Skylar 从嵌入式控制、机器视觉、机器人到数据建模与 Web 应用的项目实践。项目类型不同，但共同的主线很清楚：把传感器、算法、通信、执行机构和用户界面接起来，让一个想法成为能够阅读、调试和继续改进的工程。

每个项目都有独立目录和详细 README。可以按兴趣直接进入源码，也可以先读项目说明，了解目标、技术路线、关键模块与复现条件。仓库保留适合公开的代码、工程配置和必要资源；依赖安装目录、编译产物、重复备份和无关展示材料没有放入公开版。

## 重点可以看什么

- **跨设备联调**：视觉板、主控板与执行机构之间的数据和动作如何对应。
- **控制代码的工程细节**：PID、死区、限幅、状态机、校准和异常处理如何落到具体程序。
- **完整的数据路径**：从采样、预处理、建模到结果验证，而不只是展示最后一张图。
- **不同平台的实现方式**：STM32、MSPM0、K230、OpenMV、MATLAB、Python 与 React 在各项目中各有职责。

## 使用与来源

嵌入式项目需要匹配的板卡、外设和开发工具；部分参数取决于现场接线和标定。个别工程引用了尚未确认可再发布的第三方模块，公开版暂未收录，相关项目 README 会指出具体情况。水质检测的私有原始数据不在公开仓库中。
