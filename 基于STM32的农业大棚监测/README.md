# 基于 STM32 的农业大棚监测与控制

这个项目以 STM32 为核心，将环境采集、本地显示、阈值判断、设备控制和网络上报整合到一个温室监测工程。主循环根据工作模式与阈值管理设备状态，并通过 ESP8266 与 MQTT 通信，使现场数据能够进入远端服务。

**负责人说明：** Skylar 担任项目负责人，项目介绍聚焦温室监测系统的整体链路；厂商底层代码及第三方驱动仍以各自原声明为准。

## 系统组成

- **环境采集**：DHT11 采集温湿度，ADC 读取模拟量，SGP30 提供空气质量相关数据。
- **现场反馈**：OLED、LED 和蜂鸣器承担状态显示与提示。
- **执行控制**：继电器与模式/阈值逻辑处理设备开关。
- **网络链路**：USART2 连接 ESP8266，`mqttPublic()` 将传感器值及阈值封装为 JSON，发布到 MQTT 主题。

## 展示价值

项目同时覆盖本地闭环和远端数据通路：现场即使只看 OLED，也能理解当前采集与控制状态；联网后，JSON/MQTT 消息让数据可以进入更大的管理系统。它展示的是从传感器读数到可操作信息的完整路径。

## 复现提示

先在本地配置自己的 Wi-Fi、服务地址和 MQTT 主题，再连接对应传感器和继电器；公开代码中的阈值仅是现有工程参数，需按实际环境标定。原工程引用的 ALIENTEK 按键驱动未收录，需取得合规版本或编写替代实现后才能完整编译。厂商底层文件和原版权声明仍按各自条件使用，见[来源说明](../THIRD_PARTY.md)。
