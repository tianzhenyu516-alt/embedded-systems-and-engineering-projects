# 水质检测｜IGA-BP 统计建模

这个项目用 MATLAB 探索水质指标到等级判断的建模流程。主程序读取输入指标和目标等级，完成归一化、样本划分与网络训练；遗传算法相关代码用于参数搜索，误差函数用于评价候选解。公开内容聚焦模型方法和可复用代码，原始检测数据不公开。

**负责人说明：** Skylar 担任项目负责人。公开仓库只展示建模代码，原始水质数据保留在本地。

## 代码结构

| 文件 | 用途 |
| --- | --- |
| [`src/IGA-BP神经网络水质检测主程序.m`](src/IGA-BP神经网络水质检测主程序.m) | 数据读取、预处理、训练和结果输出 |
| [`src/decode_chromosome.m`](src/decode_chromosome.m) | 将染色体编码还原为模型参数 |
| [`src/calc_mse.m`](src/calc_mse.m) | 计算预测误差 |

## 模型流程

脚本使用 5 项输入指标预测等级。运行时先对样本归一化，再按样本量划分训练、验证和测试集，随后使用 IGA-BP 流程搜索与训练。对建模项目来说，值得关注的不只是结果数字，还包括输入列定义、划分方式、误差度量及随机性对结果的影响。若替换数据，请重新核对表格列、样本量和目标等级编码。

## 展示价值

这里把数据准备、参数搜索和误差计算放在可查看的脚本里，可以讨论为什么采用这种模型，以及怎样验证模型是否适合新样本。即使原始数据不公开，算法结构与输入约定仍能帮助阅读者复现方法。

## 数据使用

请把自己的 Excel 文件仅保存在本地 `data/water_quality_data.xlsx`，或设置环境变量 `WATER_QUALITY_DATA_FILE` 指向本地文件。主程序当前读取 `A2:E180` 作为输入、`F2:F180` 作为目标；数据排布不同就要同步修改范围。仓库没有公开原始水质数据，也不需要将数据上传到网络服务。运行需要 MATLAB 及脚本调用的相应工具箱。
