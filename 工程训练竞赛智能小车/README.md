# 工程训练竞赛｜智能小车控制工程

本工程面向一台由 STM32F407 驱动的智能小车，把视觉输入、姿态信息、行驶电机、舵机机构与显示交互集中到下位机程序。源码是理解多外设协同的案例：传感器读数经过通信解析、控制逻辑和机构驱动，最终转为可执行动作。

## 代码中的系统链路

- **感知**：主程序初始化 OpenMV 通信和 JY62 姿态模块，读取视觉坐标与航向信息。
- **决策**：`HARDWARE/control.c` 等文件组织运行过程与动作选择。
- **执行**：电机、舵机、爪子、云台和转盘由对应模块驱动。
- **交互**：按键、OLED/LCD 与串口用于模式触发、状态显示和调试。

## 文件导航

| 路径 | 作用 |
| --- | --- |
| [`src/USER/main.c`](src/USER/main.c) | 外设初始化与主循环 |
| [`src/HARDWARE/`](src/HARDWARE/) | 控制、通信、舵机与显示模块 |

## 展示价值

小车项目的难点在于各模块之间的时序：视觉目标、姿态角和按键事件可能同时变化，执行机构却必须收到一致的动作指令。下位机把这些输入汇聚在一个控制流程中，可以用来展示硬件接口整合与现场联调能力。

## 复现提示

需要匹配的 STM32F407 板卡、OpenMV、姿态传感器及机构接线；上电前应核对 PWM、串口和电机方向。工程包含厂商底层文件，并保留原工程中对 B 站“轻风雨”小车架构的参考说明，详见[来源说明](../THIRD_PARTY.md)。
