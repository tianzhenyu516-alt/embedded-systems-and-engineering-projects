# 2025 年电子设计竞赛｜视觉与运动控制工程

本项目围绕视觉定位与执行机构控制展开，收录 K230、OpenMV、舵机方案和 MSPM0G3507 主控工程。它呈现比赛开发中的系统过程：视觉算法定位目标，控制板驱动机构，多个方案通过测试与标定逐步收敛。保留不同实现是为了展示方案取舍，不代表所有版本都要同时烧录。

**负责人说明：** Skylar 担任队长，组织视觉、主控与执行机构的方案联调。本页按仓库中实际保留的代码介绍技术路线，具体第三方组件仍遵循其原声明。

## 技术路线

- **视觉端**：`src/k230/` 中有钢珠识别脚本和模型；`src/OpenMV/` 保存 OpenMV 视觉及步进方案。
- **执行端**：`src/舵机方案/` 保存舵机实验，可以与步进方案对照执行精度和响应。
- **主控端**：`src/主控工程/` 保存解包后的 MSPM0G3507 工程、控制模块、通信和板级配置。
- **联调重点**：视觉坐标与机构坐标的映射、串口数据格式、PID 参数及输出限幅都依赖现场标定。

## 展示价值

这份工程的优势是方案之间可以相互参照：视觉端解决“目标在哪”，主控端解决“怎样稳定到达”，舵机和步进实验体现不同执行方式的取舍。对于需要现场调试的竞赛项目，保留参数与试验版本本身也能说明问题如何被逐步定位。

## 使用说明

先确定板卡和执行机构，再选择对应子工程。K230/OpenMV 代码需要设备固件及摄像头环境；MSPM0 工程需要 TI 对应工具链和外设连接。公开版保留源码、模型及工程配置，省略重复压缩包、视频和编译产物。厂商支持文件按各自原声明使用，详见[来源说明](../THIRD_PARTY.md)。
