# 小青菜智能检测与分拣｜视觉、称重与执行联动

本项目把视觉判断、重量采集、状态管理和执行机构串成一条分拣流程。它的重点是系统协作：视觉侧识别目标状态，STM32F103 读取称重模块并控制输送与分拣动作，显示模块把运行状态反馈给现场人员。

## 技术看点

- **称重与校准**：HX711 负责重量数据采集；F103 主程序包含开机零点校准和多次采样处理。
- **流程组织**：`F103/Core/` 中的状态机、数据管理与错误模块将判断和执行拆开。
- **机构协同**：继电器、舵机、信号输入和 OLED 的配合可在 STM32 工程中追踪。
- **视觉实验**：K230/视觉识别目录保存黄叶检测与显示相关脚本，可对照嵌入式主控逻辑理解两端职责。

## 展示价值

分拣设备要处理连续的物料，而不是只判断单张图片。状态机、称重校准、异常记录与执行机构控制放在同一流程中，使这个项目能展示如何把一个识别结果转化为可靠、可观察的现场动作。

## 阅读与复现

建议先看 `F103/User/main.c` 的初始化和主循环，再看 `F103/Core/` 的状态切换，最后对照 `STM32工程/Hardware/` 与 K230 脚本理解输入、判断和动作的对应关系。实际运行需确认 HX711 校准系数、传感器接线、执行机构方向、阈值与视觉环境。不同目录保存了不同阶段的实现，请依据自己的硬件选择工程，不要把它们直接合并编译。第三方底层代码保持原声明，见[来源说明](../THIRD_PARTY.md)。
