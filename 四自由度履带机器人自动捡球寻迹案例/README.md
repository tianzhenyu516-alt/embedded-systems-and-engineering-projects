# 四自由度履带机器人｜寻迹与自动捡球

该案例把移动底盘、视觉识别和四自由度机械臂放进同一控制流程：机器人沿线行驶，识别目标并调整位置，再由舵机机构执行抓取。工程代码展示了一个具体的“移动—感知—对准—动作”闭环，适合研究 OpenMV 场景下多模块如何配合。

**负责人说明：** Skylar 担任项目负责人。源码中原有的作者标识继续保留，负责人身份不替代这些署名。

## 主要模块

- [`src/main.py`](src/main.py)：运行入口，包含颜色阈值、舵机初始位置、动作流程和多组 PID 参数。
- [`src/linetraking.py`](src/linetraking.py)：视觉寻迹。
- [`src/umotor.py`](src/umotor.py)：底盘电机控制。
- [`src/ultrasonic.py`](src/ultrasonic.py)：超声波测距。
- [`src/ubluetooth.py`](src/ubluetooth.py)：蓝牙通信与车体状态。
- [`src/pid.py`](src/pid.py)：反馈控制基础模块。

## 展示价值

机器人同时涉及底盘运动与机械臂动作，视觉误差不能简单当成舵机角度。代码中的目标跟随、角度偏置和距离估计提供了具体的调试切口，可以说明视觉坐标怎样逐步变成抓取动作。

## 调试重点

先在自己的装置上校准颜色阈值、摄像头视角、轮速、舵机中位和机械臂长度，再测试寻迹与抓取。`main.py` 中的舵机偏置、抓取角度和测距系数是具体硬件参数。主程序和部分模块保留 `Admin`、`mengfan_zheng` 等原有作者标识；整理或改造项目时仍应保留这些信息，见[来源说明](../THIRD_PARTY.md)。
