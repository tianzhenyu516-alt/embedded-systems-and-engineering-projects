# 健康守护｜健康管理 Web 应用

这是一个覆盖用户页面、设备连接、健康信息展示和服务端接口的 Web 项目。它把健康数据、交互页面与后端服务放在同一工程中：前端负责用户看见和操作的部分，后端负责接口、配置、数据访问及请求处理。适合展示从页面功能到服务组织的全栈开发思路。

## 功能与实现

- **健康概览**：用户仪表盘、趋势页面和互动看板组织健康信息。
- **设备连接**：代码包含 Fitbit 与涂鸦设备连接相关页面及回调流程；实际接入需要各平台自己的配置。
- **服务体验**：健康建议、饮食、咨询与在线医院等页面和组件体现多场景交互设计。
- **管理能力**：管理端、子管理端与 API 监控页面提供运营和检查入口。
- **后端基础**：Express 服务、数据库配置、认证、错误处理、日志与限流分模块组织。

## 展示价值

这个项目有丰富的页面类型，也有支撑页面运行的服务端结构。读者既可以看用户如何完成登录、查看趋势与连接设备，也可以继续追踪请求怎样经过认证、配置和数据访问。这样的前后端对应关系，比单独展示静态界面更能体现完整产品的组织能力。

## 本地启动

需要 Node.js 18 及 npm 9 或更新版本。在 `src/backend/` 与 `src/frontend/` 分别执行 `npm install`、`npm run dev`。先将 `src/backend/.env.example` 复制为仅保存在本机的 `.env`，并按实际数据库、设备平台和服务配置填写。不要提交 `.env` 或真实用户健康数据。外部服务、模型和设备需要各自的账号、权限与资源；仅下载源码不能自动获得完整在线能力。

公开版收录的是脱敏后的前后端源码，不含本地数据库、依赖安装目录及来源未核实的外部模型。第三方库和素材按其各自许可使用，见[来源说明](../THIRD_PARTY.md)。
