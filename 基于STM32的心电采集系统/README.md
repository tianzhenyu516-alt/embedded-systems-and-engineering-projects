# 基于 STM32 的心电信号采集与处理

本工程围绕“把连续的模拟心电信号变成可观察的数据”展开，包含 ADC 采样、DMA 缓冲、数字滤波和串口输出。相比单次读数，它更关注连续采集中的缓冲切换、工频干扰与基线变化，是一个把嵌入式数据通路和信号处理结合起来的例子。

**负责人说明：** Skylar 担任项目负责人。工程介绍说明采集与处理流程，不改变 CMSIS、STM32 等底层文件的原有权利声明。

## 主要流程

1. ADC 将模拟输入转换成采样值，DMA 将连续数据放入缓冲区。
2. 程序根据缓冲状态处理批量数据，减少采集与计算互相阻塞。
3. `main.c` 中的 50 Hz 陷波、高通与 SG 平滑相关代码用于观察滤波处理过程。
4. 处理后的数据通过串口模块输出，供外部显示或分析。

## 阅读入口

- [`src/USER/main.c`](src/USER/main.c)：采集缓冲与滤波流程。
- [`src/USER/adc.c`](src/USER/adc.c)、[`src/USER/usart1.c`](src/USER/usart1.c)：采集和输出接口。
- `src/USER/sg_filter.c`、`src/USER/Matrix_operation.c`：信号处理相关实现。
- `src/USER/STM32-DEMO.uvprojx`：Keil 工程。

## 展示价值

连续信号处理同时考验采样链路和算法链路：前者要稳定地把数据送入缓冲区，后者要解释每一级滤波对波形的影响。工程保留采样、缓冲和滤波的具体实现，便于讨论取样时序与信号质量之间的关系。

## 使用说明

需要匹配的 STM32F1 硬件、模拟前端及安全的测试信号。采样率、滤波系数、输入幅度和串口格式应按实际设备重新确认。该工程用于学习和展示采集链路，不作为医疗诊断工具。CMSIS 与 STM32 底层支持文件保留原声明，见[来源说明](../THIRD_PARTY.md)。
