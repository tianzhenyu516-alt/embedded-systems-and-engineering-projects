# 2026 年电子设计竞赛｜视觉感知与闭环控制

这里集中展示 2026 年电赛相关的视觉和控制代码。K230 程序处理钢珠位置、目标区域与画面传输，STM32F103 和 MSPM0G3507 工程保留不同控制板的实现。看点在于将摄像头观测、位置误差、控制输出和物理执行机构串成可调试的链路。

**负责人说明：** Skylar 担任队长，负责主控开发与项目联调。以下技术介绍对应仓库中公开的工程内容；厂商支持包与第三方模块仍以各自原声明为准。

## 工程亮点

- **视觉反馈**：`src/视觉代码/main.py` 中可见 K230 图像处理、钢珠位置计算、目标判断与控制参数。
- **控制策略**：源码保留 PID、限幅、死区和稳定时间等参数，便于研究目标识别后的平稳控制。
- **双板实验**：`src/f103c8t6/` 和 `src/mspm0g3507/` 展示串口、驱动和控制模块的衔接。
- **现场观察**：视觉程序有手机画面传输逻辑，方便观察识别结果；实际使用要根据自己的网络环境配置。

## 展示价值

视觉闭环的难点不在单独识别钢珠，而在让每一帧的位置变化真正影响机构动作，并在接近目标时避免反复振荡。项目中的中心区、输出限制和稳定判定等设计，让控制链路的调试思路比“识别成功”更完整，也给后续参数整定留下清晰入口。

## 复现与边界

先确认硬件版本，再校准相机位置、机构中心、舵机方向、串口和 PID 参数。阈值、长度及端口都是现有装置的配置，换设备后不宜直接照搬。公开版未收录原工程所引用的部分 ALIENTEK、无名创新和缺少许可文件的 eMPL 模块，因此相关工程需要补齐合规来源或替代驱动后才能完整构建；现有第三方声明保持原样，见[来源说明](../THIRD_PARTY.md)。
